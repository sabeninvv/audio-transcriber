### Разбор значений ENV
Превращает строковые значения переменных окружения в типизированные значения конфигурации.

* `_parse_csv_values` — разбирает список через запятую, отбрасывает пустые элементы; при отсутствии или пустом результате отдаёт дефолт.
* `_parse_reference_values` — разбирает data URL известных спикеров, разделённые `|` или переводом строки.
* `_parse_positive_int` — парсит положительное целое с дефолтом; иначе `TranscriptionError` с именем переменной.
* `_parse_bool` — считает истиной `1`, `true`, `yes`, `on` без учёта регистра.
