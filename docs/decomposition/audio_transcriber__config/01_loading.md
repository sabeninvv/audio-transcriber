### Загрузка конфигурации
Собирает `TranscriptionConfig` из окружения: провайдер, ключ API, модели, промпт, подсказки языка и спикеров. OpenRouter подключается через `OPENAI_BASE_URL` SDK при провайдере `openai`.

* `load_config` — читает ENV (или переданный mapping); провайдер из `TRANSCRIPTION_PROVIDER` (по умолчанию `openai`), ключ строго из переменной провайдера (`API_KEY_ENV_NAMES`: `OPENAI_API_KEY`, `API_ELEVENLABS_API_KEY` или `GEMINI_API_KEY`), иначе `TranscriptionError`. Дефолт `TRANSCRIPTION_MODEL` берётся из `DEFAULT_MODELS`: `gpt-transcribe`, `scribe_v2` или `gemini-3.8-flash`. Дефолтные ключевые слова есть у OpenAI и Gemini, у ElevenLabs без явного `TRANSCRIPTION_KEYWORDS` их нет (keyterms дороже на 20%). `TRANSCRIPTION_SUBTITLE_MODEL` (по умолчанию `whisper-1`) для OpenAI допускается только `whisper-1` или `openai/whisper-1`. Явно заданная переменная из `UNSUPPORTED_ENV_NAMES[provider]` → `TranscriptionError`: у ElevenLabs это промпт, модели субтитров и диаризации, known speakers; у Gemini то же без промпта. Gemini с `TRANSCRIPTION_DIARIZATION_ENABLED=true` → `TranscriptionError`. Проверяет согласованность known speakers с диаризацией.
