### Загрузка конфигурации
Собирает `TranscriptionConfig` из окружения: провайдер, ключ API, модели, промпт, подсказки языка и спикеров. OpenRouter подключается через `OPENAI_BASE_URL` SDK при провайдере `openai`.

* `load_config` — читает ENV (или переданный mapping); провайдер из `TRANSCRIPTION_PROVIDER` (по умолчанию `openai`), ключ строго из переменной провайдера (`OPENAI_API_KEY` или `API_ELEVENLABS_API_KEY`), иначе `TranscriptionError`. Дефолт `TRANSCRIPTION_MODEL` — `gpt-transcribe` для OpenAI и `scribe_v2` для ElevenLabs; дефолтные ключевые слова только у OpenAI, у ElevenLabs без явного `TRANSCRIPTION_KEYWORDS` их нет (keyterms дороже на 20%). `TRANSCRIPTION_SUBTITLE_MODEL` (по умолчанию `whisper-1`) для OpenAI допускается только `whisper-1` или `openai/whisper-1`. Для ElevenLabs явно заданная переменная из `OPENAI_ONLY_ENV_NAMES` (промпт, модели субтитров и диаризации, known speakers) → `TranscriptionError`. Проверяет согласованность known speakers с диаризацией.
