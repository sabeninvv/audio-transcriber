### Промпт и диагностика
Собирает промпт с контекстом предыдущего чанка и достаёт тело ответа для логов ошибок.

* `_build_prompt` — объединяет базовый промпт и хвост предыдущего чанка с инструкцией не повторять его.
* `_extract_response_text` — безопасно достаёт текст HTTP-ответа из ошибки SDK для логирования.
