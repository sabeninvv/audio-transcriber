### Инструкция для модели
Собирает текст, который заменяет Gemini параметры промпта, языков и глоссария из OpenAI Audio API.

* `GeminiTranscriptionClient._instruction` — построчно склеивает фиксированную инструкцию «расшифруй дословно, верни только текст», базовый промпт, строку `Languages: ...` и строку `Glossary: ...`; пустые строки пропускает.
